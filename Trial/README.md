# Spider Escape 2.0.2 trial

Run game.py with pygame installed, or use the trial Mac ZIP. Select player count,
quiz, and car colors by clicking the start screen options or using the displayed
keyboard shortcuts. Click START or press Enter to play. Solo/right uses arrows and Space; left
uses WASD and Z. Each living player gains one shot every ten seconds; ammo pickups add extra shots. Armor, slow and repellent last ten
seconds. Two-player mode has a shared score and its own best score; the game ends
when both cars are lost. The Spanish quiz is disabled for two players.

The 2.0.2 trial is a separate build from the frozen 2.0.1 archive in Distribution.
