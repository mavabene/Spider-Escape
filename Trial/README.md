# Spider Escape trial

Run game.py with pygame installed, or use the trial Mac ZIP. Select player count,
quiz, and car colors on the start screen. Solo/right uses arrows and Space; left
uses WASD and Z. Ammo comes only from pickups. Armor, slow and repellent last ten
seconds. Two-player mode has a shared score and its own best score; the game ends
when both cars are lost. The Spanish quiz is disabled for two players.
