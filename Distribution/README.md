# Frozen Spider Escape builds

These ZIPs are archived distribution copies. Do not overwrite them when creating future versions. Build new versions under a new filename, and keep working files outside this folder.

The ZIPs contain Apple Silicon Mac apps with locally valid code signatures. They are not notarized by Apple, so macOS may require a per-app Open Anyway approval.

The Original Mac ZIP was rebuilt from `Spanish_Racing_Mac_Builder/Original_Game_Files`; packaging-only startup adjustments were applied to the copy used for the build. The archived source files remain unchanged.
